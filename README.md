# Campaign Lens｜AI 营销内容风险审阅原型

一个面向营销策划人员的本地文案审阅工具。输入中文营销文案，获得可追溯的规则命中、风险说明与修改提示；无需账号、API Key 或上传文案。

这个项目连接了我的法学背景、AIGC 内容研究和营销工作流兴趣。它是作品集原型，规则仅用于发现值得人工复核的线索，**不构成法律意见，也不能判断文案是否合规**。

## 运行

需要 Python 3.10+，无第三方依赖。

```bash
python -m http.server 8000
```

打开 `http://localhost:8000`。也可以直接打开 `index.html`。所有分析均在浏览器本地完成。

## 功能

- 检查绝对化用语、效果承诺、限时促销、隐私及知识产权相关表述
- 显示命中原文、原因、核查问题和可操作的改写方向
- 提供 GDPR 科普、电商宣传和游戏促销三个虚构示例
- 一键复制 Markdown 审阅清单

## 方法与边界

`rules.js` 保存可审计的启发式规则；`app.js` 执行匹配、排序和报告生成。命中只代表需要核实，未命中也不代表安全。规则可能误报或漏报，具体判断取决于事实、证据、发布地区、平台及当时有效的规定。示例均为虚构，不使用简历中的模拟数据冒充真实业务结果。
