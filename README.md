# Campaign Lens｜营销内容合规风险审查

输入中文营销文案，查看可能需要人工核查的合规风险表述、命中原因和修改方向。工具在浏览器本地运行，无需账号或上传文案。

规则仅用于发现值得人工复核的线索，**不构成法律意见，也不能判断文案是否合规**。

## 运行

需要 Python 3.10+，无第三方依赖。

```bash
python -m http.server 8000
```

打开 `http://localhost:8000`。也可以直接打开 `index.html`。所有分析均在浏览器本地完成。

## 功能

- 检查绝对化用语、效果承诺、限时促销、隐私及知识产权相关表述
- 显示命中原文、原因、核查问题和可操作的改写方向
- 一键复制 Markdown 审阅清单

## 方法与边界

`rules.js` 保存可审计的启发式规则；`app.js` 执行匹配、排序和报告生成。命中只代表需要核实，未命中也不代表安全。规则可能误报或漏报，具体判断取决于事实、证据、发布地区、平台及当时有效的规定。
